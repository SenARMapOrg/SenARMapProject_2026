マップを埋め込む

生田キャンパスのフロアマップや、教室までの道順を、自分のサイトやブログに載せられます。内容を選ぶと貼り付けるコードができるので、ページの HTML にそのまま貼ってください。

載せるもの

見た目

URL で指定する

コードの src は、次のパラメータを組み合わせた URL です。教室名は教室検索ナビと同じ書き方で、教室名が1つの号館にしか無ければ号館は省けます。

載せるものパラメータ例
教室の場所room・bldg/embed/?room=10301
道順from・from_bldg・to・to_bldg
（イベントの展示は from_event・to_event）		/embed/?from=10301&to=131&to_bldg=1
フロアマップbldg・floor/embed/?bldg=10&floor=3
共通elevator=0（エレベーターを使わない）
header=0（上の帯を出さない）
floors=0（階の切り替えを出さない）

ページから操作する

埋め込んだマップとは postMessage でやり取りできます。表示を差し替えるときは、URL と同じパラメータを送ります。

const frame = document.querySelector("iframe");
// 行き先を変える
frame.contentWindow.postMessage({ type: "ikunavi:show", params: { from: "10301", to: "131", to_bldg: 1 } }, "https://iku-navi.net");
// 道順の3つ目の区間を見せる（0 から数える）
frame.contentWindow.postMessage({ type: "ikunavi:segment", index: 2 }, "https://iku-navi.net");
// マップからの知らせ（ready・segment・error）
addEventListener("message", e => {
  if (e.origin === "https://iku-navi.net" && e.data?.source === "ikunavi-embed") console.log(e.data);
});

載せるときのお願い

  • マップの右下の「IKU NAVI」の表示は消さないでください。
  • IKU NAVI は専修大学 ネットワーク情報学部の学生プロジェクトが作っているもので、大学の公式サービスではありません。教室や道順の情報は変わることがあります。

IKU NAVI は、専修大学 ネットワーク情報学部の学生プロジェクト「生亀プロジェクト」が作っている、生田キャンパスの教室検索・道案内アプリです。大学の公式サービスではありません。
