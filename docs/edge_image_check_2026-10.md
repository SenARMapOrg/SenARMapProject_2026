# 経路写真の数の食い違いと R2 の中身（2026-10-23）

`data/edge_image.csv` では写真が 1199 あるのに、IKU NAVI ツールの画像チェックでは開発環境・本番とも 1107 になる理由を調べた結果。
あわせて R2（`iku-navi-image`）のファイル一覧を取り、CSV と照合した。

## 結論

データが壊れているのではなく、数えているものが違う。

| 数 | 内容 |
|---|---|
| **1199** | `edge_image.csv` の id がある行（ほかは `,0,0,0_to_0.jpg` の 1807 行と空の 489 行。スプレッドシートの空き行） |
| −72 | 同じ from→to が2回以上書かれている行（69 区間）。ファイル名も同じで、同じ1枚を指している |
| **1127** | 区間ごとに数えた写真。`/api/edge_images` は区間ごとに1つにまとめて返すので、本番 API の件数もこれ |
| −20 | 今の経路（edge.csv）に無い区間の写真。ナビでは使われない |
| **1107** | 今の経路で使われる写真。画像チェックはグラフの区間を元に数えるので、どの環境でもこの数になる |

今のナビで使う 1107 枚は、すべて R2 にある（欠けは無い）。

## R2 の中身（1170 件）

| 数 | 中身 |
|---|---|
| 1143 | 区間の写真（`<from>_to_<to>.jpg`） |
| 23 | 4号館の古い名前の写真（`400001_400016.jpg` のように `_to_` が無い。`.JPG` も混じる）。どこからも使われていない |
| 3 | `Straight.png`・`left.png`・`right.png`（ナビの矢印。`navi/script/state.js` が使う） |
| 1 | `tools/install.sh`（IKU NAVI ツールのインストーラ） |

CSV との照合:

- **書き間違いと思われるもの（1件）**: CSV の id 1112 は `200025→200008` だが、この区間は経路にも R2 にも無い。
  R2 には `200025_to_300008.jpg` があり、この区間（2号館→3号館）は今の経路にあるのに CSV に無い。to の `300008` を `200008` と入れたものと思われる
- **CSV に無い写真（16 枚）**: 8号館の `800042`〜`800050` の区間。今の経路には無い
  （`800042_to_800043` `800042_to_800044` `800043_to_800042` `800044_to_800042` `800044_to_800045` `800044_to_800046` `800045_to_800044` `800046_to_800044` `800046_to_800047` `800046_to_800048` `800047_to_800046` `800048_to_800046` `800048_to_800049` `800048_to_800050` `800049_to_800048` `800050_to_800048`）

## 整理するなら（スプレッドシート側で）

CSV はスプレッドシートから更新しているので、こちらでは手を入れていない。

1. id 1112 の to を `300008` に直す（直すと、使われる写真が 1108 になる）
2. 重複の行を消す（下の表。どれか1行を残す）
3. 経路に無い 19 区間（id 1112 以外）を、撮り直す・行を消す・edge.csv 側を戻す のどれにするか決める
4. 必要なら R2 の使われていない写真（4号館の古い名前 23 枚・8号館 16 枚）を消す

## R2 の一覧の取り方

wrangler には一覧を出すコマンドが無い（`wrangler r2 object` は get・put・delete だけ）。
`wrangler login` 済みなら、そのトークンで Cloudflare の API から取れる。1回で最大 1000 件で、それ以上は返ってくる `cursor` を付けて続きを取る。

```bash
TOKEN=$(grep oauth_token ~/Library/Preferences/.wrangler/config/default.toml | cut -d'"' -f2)
ACCOUNT=$(npx wrangler whoami 2>/dev/null | grep -oE '[0-9a-f]{32}' | head -1)
curl -s -H "Authorization: Bearer $TOKEN" \
  "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT/r2/buckets/iku-navi-image/objects?per_page=1000"
# 続き: ...&cursor=<前の結果の result_info.cursor>
```

トークンの場所は macOS の場合（Linux は `~/.config/.wrangler/config/default.toml`）。
