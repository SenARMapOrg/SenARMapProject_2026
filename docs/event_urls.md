# イベントのナビURL一覧

`data/event.csv` から `programs/3D_Graph/event_urls.py` で書き出したもの。手で直さず、event.csv を変えたら実行し直す。
URL を開くと、目的地にその展示が入った状態でナビが開く（イベントモードも自動で有効）。
場所が「未設定」のイベントは、event.csv に場所を入れるまでURLを開いても目的地に入らない。
